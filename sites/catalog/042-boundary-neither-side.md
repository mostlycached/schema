| Dimension | Value | Constraint |

## Strategy Space

### Path A: Liminal dwelling
```
Boundary → suspend → dwell at edge → neither here nor there
```
**Payoff**: Experience the threshold as place.

### Path B: Locate (fails)
```
Boundary → "where exactly?" → zero width → Sorites paradox
```
**Payoff**: Discovery: boundaries can't be precisely located.

### Path C: Abstract
```
Boundary → all boundaries → the boundary makes the sides, not sides the boundary
```
**Payoff**: General principle extracted.

### Path D: Cross
```
Boundary → step to one side → leave the site → become A or B
```
**Payoff**: Exit liminality; transformation.
