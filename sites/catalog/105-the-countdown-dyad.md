# The Countdown Dyad

**Practice**: Sociology
**Base**: `dyadic` + `danger` + `enclosed`
**Layer 2**: `temporal = countdown` (Finite Resource/Time)

---

## State Space

You are **dying on a schedule** — the enclosure is now a clock.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Resource | Scarce | Oxygen/Heat/Strucutre failing |
| Action | Compressed | Must choose *now* |
| Future | Truncated | No "tomorrow" consequences |
| Relation | Final | This is the last person |

**Tension**: Maximum (Existential Urgency).

---

## Action Set

In **Sociology** practice, moves are forced by the clock:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Confess** | *commit* | Say the unsaid | Truth hurts (but brief) |
| **Bargain** | *branch* | Try to fix the machine | Wasted last moments |
| **Comfort** | *connect* | Lie ("it will be okay") | False peace |
| **Sacrifice** | *resolve* | Give oxygen to other | Death / Survivor Guilt |

**Blocked moves**:
- *Defer* — blocked by clock
- *Plan* — blocked by no-future
- *Wait* — blocked by diminishing resource

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Confess → truth** | +cleanliness | Die known / Die hated |
| **Bargain → fix** | +hope | Die working (distracted) |
| **Comfort → lie** | +peace | Die deluded but calm |
| **Sacrifice → give** | +meaning | One lives (haunted) |
| **Transfer → ×deathbed** | +frame | The final conversation |
| **Transfer → ×sacrifice** | +frame | The mathematical ethics |

## Global Operations

| Operation | Layered Consequence |
|-----------|--------------------|
| **GENERATE** | Produces: "last words", "testaments", "heroic suicide", "brutal predation" |
| **TRANSFER** | Maps to: Titanic (sinking), hospice (dying), Trolley Problem (forced choice) |
| **DISSOLVE** | At T=0 (Death or Rescue) |
| **EMERGE** | Silence, a final confession, or a corpse |

## Strategy Space

### Path A: The Truth
```
Countdown starts → "I never loved you" → die in honest hate
```
**Payoff**: Radical authenticity.

### Path B: The Lie
```
Countdown starts → "I love you" (lie) → die in fake love
```
**Payoff**: Mercy.

### Path C: The Work
```
Countdown starts → ignore other → fix wires → die trying
```
**Payoff**: Denial of death.
