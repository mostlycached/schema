# The Social Caldera

**Practice**: Sociology
**Speculation**: Transfer/Scale Shift (Planetary → Social)

---

## State Space

You are on **the thin crust of normalcy** — overlying a massive, collapsed social chamber.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ground | Unstable | Society built on previous collapse |
| Pressure | Rising | Invisible accumulation of tension |
| Visibility | Hidden | Looks like a meadow/city |
| Scale | Collective | Can't face it alone |

**Tension**: High (It happened before; it will happen again).

---

## Action Set

In **Sociology** practice, your moves are structural awareness operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Drill** | *narrow* | Test the depth of stability | Releasing the pressure |
| **Build** | *suspend* | Construct on the crust | Collapse risk |
| **Listen** | *witness* | Hear the rumble below | Paranoia |
| **Vent** | *channel* | Controlled release | Social unrest |

**Blocked moves**:
- *Seal* — pressure is too great
- *Ignore* — the ground shakes

## Strategy Space

### Path A: The Developer (Build)
```
Caldera → "looks flat" → build city → ignore history → catastrophe
```
**Payoff**: Short-term profit; total loss.

### Path B: The Activist (Drill)
```
Caldera → "unstable" → expose the fault → trigger limits → radical change
```
**Payoff**: Truth; acceleration of crisis.

### Path C: The Reformer (Vent)
```
Caldera → pressure rising → create vents → elections/releases → maintain crust
```
**Payoff**: Stability; postponement of structural change.

### Path D: The Cassandra (Listen)
```
Caldera → hear rumble → warn others → ignored → "I told you so"
```
**Payoff**: Right but powerless.
