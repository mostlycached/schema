# The Eruption You Must Watch

**Practice**: Contemplation
**Constraint**: `gestures.blocked = [RETREAT, LOOK_AWAY]` (Forced Witness)

---

## State Space

You are **pinned by the sublime** — the event demands total attention.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Event | Catastrophe | Overwhelming magnitude |
| Agency | Paralyzed | Eye cannot close |
| Distance | Safe/Unsafe | Doesn't matter; can't move |
| Duration | Unbearable | Time dilates |

**Tension**: Maximum (The obligation to see what destroys).

---

## Action Set

In **Contemplation** practice, your moves are attention operations under duress:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Stare** | *witness* | Drink the details | Trauma / blindness |
| **Record** | *capture* | mediate via screen/memory | Miss the reality |
| **Analyze** | *detach* | Intellectualize to survive | Dissociation |
| **Scream** | *express* | Vocalize the horror | Ineffective |

**Blocked moves**:
- *Look Away* — blocked by magnitude
- *Run* — blocked by fascination/paralysis
- *Intervene* — blocked by scale

## Strategy Space

### Path A: The Open Eye
```
Event starts → try to look away → cannot → forced to record every detail → trauma
```
**Payoff**: The burden of truth.

### Path B: The Filter
```
Event starts → raise camera → look through lens → convert to image → safety
```
**Payoff**: Mediation as shield.

### Path C: The Statue
```
Event starts → paralysis → turn to stone → become part of the landscape
```
**Payoff**: Cessation of agency.
