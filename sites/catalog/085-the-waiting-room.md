# The Waiting Room

**Practice**: Contemplation

---

## State Space

You are at **pure duration** — time without content.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontological | Pause | Suspension |
| Agency | Passive | Cannot act |
| Environment | Sterile | Designed for waiting |
| Outcome | Unknown | Assessing |

**Tension**: Low (Boredom) to High (Anxiety).

---

## Action Set

In **Contemplation** practice, your moves are temporal operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Wait** | *suspend* | Endure time | Boredom |
| **Distract** | *branch* | Phone/Magazine | Fragmentation |
| **Observe** | *witness* | Room/People | Banality |
| **Worry** | *speculate* | "What comes next?" | Anxiety |

**Blocked moves**:
- *Accelerate* — not in control
- *Leave* — lose your spot

---

## Strategy Space

### Path A: The Killer
```
Wait -> Phone -> Magazine -> Sleep -> Wasted time
```
**Payoff**: Time passes unnoticed.

### Path B: The Worrier
```
Wait -> Rehearse -> Check clock -> Panic -> Exhaustion
```
**Payoff**: Illusion of control; suffering.

### Path C: The Monk of the Plastic Chair
```
Wait -> Sit -> Breathe -> Accept -> Presence
```
**Payoff**: Radical acceptance of non-doing.
