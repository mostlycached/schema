# The Victim Who Doesn't Overcome

**Practice**: Contemplation

---

## State Space

You are at **permanent damage** — the wound that becomes the world.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontological | State | Brokenness |
| Arc | Flat | No recovery |
| Identity | Victim | Defined by harm |
| Future | Foreclosed | Same as present |

**Tension**: High (Expectation of healing vs. Reality of damage).

---

## Action Set

In **Contemplation** practice, your moves are endurance operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Exist** | *suspend* | Continue broken | Despair |
| **Show** | *witness* | Reveal damage | Pity/Revulsion |
| **Replay** | *narrow* | The event returns | Retraumatization |
| **Reject** | *branch* | Refuse "healing" | Isolation |

**Blocked moves**:
- *Overcome* — failed
- *Grow* — blocked
- *Forget* — etched in

## Strategy Space

### Path A: The Failed Hero
```
Try to heal -> Fail -> Try -> Fail -> Exhaustion
```
**Payoff**: Effort recognized; result denied.

### Path B: The Resentful
```
Stay broken -> Blame world -> Demand care -> Be rejected
```
**Payoff**: Externalized pain; loss of support.

### Path C: The Ruin
```
Accept damage -> Inhabit brokenness -> Be valid debris
```
**Payoff**: Ontological validity; tragedy.
