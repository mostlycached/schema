# The Art That Is Bad

**Practice**: Design

---

## State Space

You are at **creative failure** — the soul revealed as mediocre.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontological | Object | Bad Art |
| Agency | Creator | You made it |
| Quality | Low | Objective/Subjective failure |
| Permanence | High | It exists |

**Tension**: Retrospective (Hope → Cringe).

---

## Action Set

In **Design** practice, your moves are evaluation operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Assess** | *critique* | "It is bad" | Depression |
| **Destroy** | *dissolve* | Burn/Delete | Denial |
| **Publish** | *commit* | Show it anyway | Public humiliation |
| **Rationalize** | *reframe* | "It's a process" | Delusuion |

**Blocked moves**:
- *Unmake* — time arrow
- *Improve* — the work is finished (and bad)

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Critique → truth** | +clarity | "I am mediocre" |
| **Destroy → hide** | +relief | Secret shame |
| **Commit → show** | +courage | Public judgment |
| **Reframe → process** | +comfort | Continued mediocrity |
| **Transfer → ×cliché** | +frame | You are derivative |
| **Transfer → ×skill** | +frame | Gap between taste and ability |

| Operation | Design Consequence |
|-----------|-------------------|
| **GENERATE** | Produces: "kitsch", "amateurism", "content farms", "guilty pleasures" |
| **TRANSFER** | Maps to: evolution (dead ends), noise (signal/noise), waste (creative) |
| **DISSOLVE** | Through destruction or forgetting |
| **PARASITIZE** | The Filter intercepts the critique; Instagram makes the mediocre look aesthetic |
| **EMERGE** | A thrift store shelf, embarrassment, or ironic appreciation |

---

## Strategy Space

### Path A: The Delusion
```
Make bad art -> Call it "style" -> Show everyone -> Be ignored
```
**Payoff**: Ego protection; public pity.

### Path B: The Cringe
```
Make bad art -> Realize -> Hide it -> Shame
```
**Payoff**: Taste preservation; secret failure.

### Path C: The Acceptance
```
Make bad art -> "This is bad" -> Keep making -> Get better?
```
**Payoff**: Growth (maybe); endurance of mediocrity.
