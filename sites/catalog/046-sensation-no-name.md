# The Sensation With No Name

**Practice**: Writing

---

## State Space

You are at **the lexical gap** — experience waiting for a word.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Sensation | Distinct | You feel it clearly |
| Word | ABSENT | No name in your language |
| Gap | Structural | Vocabulary has holes |

**Tension**: Medium (the gap nags).

---

## Action Set

In **Writing** practice, your moves are naming operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Dwell** | *suspend* | Live with the nameless | Perpetual gap |
| **Approximate** | *narrow* | What's the closest term? | Inadequate |
| **Coin** | *create* | Make a new word | May not stick |
| **Borrow** | *import* | Use foreign term | Cultural import |
| **Describe** | *circumlocute* | Talk around it | Wordy |

**Blocked moves**:
- *Name directly* — the word doesn't exist

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Suspend → with nameless** | +dwelling | Live in lexical gap |
| **Narrow → this sensation** | +attention | Attend to exact feeling |
| **Narrow → closest word** | +approximation | Inadequate but available |
| **Expand → all unnamed** | +scope | Everything felt but unworded |
| **Expand → all languages** | +inquiry | Does any language have a word? |

## Strategy Space

### Path A: Dwell with nameless
```
Sensation → no word → dwell → accept the gap
```
**Payoff**: Live with incompleteness.

### Path B: Approximate
```
Sensation → no word → "closest is..." → inadequate but available
```
**Payoff**: Working vocabulary despite imprecision.

### Path C: Coin
```
Sensation → no word → make one up → neologism
```
**Payoff**: Creative resolution; word may or may not spread.

### Path D: Borrow
```
Sensation → no word → "Germans have a word" → import
```
**Payoff**: Cultural import; precision from elsewhere.
