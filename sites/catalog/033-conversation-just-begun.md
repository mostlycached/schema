## Strategy Space

### Path A: Safe opening
```
Begin → light topic → volley → see where it goes
```
**Payoff**: Low risk; low depth; normal.

### Path B: Direct depth
```
Begin → go deep immediately → "What really matters to you?"
```
**Payoff**: High risk; potential intimacy or rejection.

### Path C: Meta
```
Begin → "What should we talk about?" → negotiate topic
```
**Payoff**: Unusual; collaborative; self-aware.

### Path D: Radical openness
```
Begin → suspend → silence → let them lead
```
**Payoff**: Radical receptivity; social pressure.
