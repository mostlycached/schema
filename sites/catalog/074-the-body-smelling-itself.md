## Strategy Space

### Path A: The Hygienic
```
Smell → Panic → Wash/Cover → Relief
```
**Payoff**: Social safety; body denial.

### Path B: The Animal
```
Smell → Sniff → Recognize → "That's me"
```
**Payoff**: Primal identity; absence of shame.

### Path C: The Vigilant
```
Constant monitoring → Fear of smell → Pre-emptive washing
```
**Payoff**: Anxiety; sanitized exhaustion.
