# The Blank Page Before the First Mark

**Practice**: Design

---

## State Space

You are in **maximum possibility space** — pre-constraint territory where every choice is available.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontology | Virtuality | Pure potential; nothing actualized |
| Action space | ~∞ | Any mark, any word, any direction |
| Structure | Paradoxical | Maximum freedom = maximum paralysis |

**Tension**: High. The page stares back. Any mark constrains all subsequent marks.

---

## Action Set

In **Design** practice, your moves are generative operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Constrain** | *narrow* | Choose medium, genre, audience, scale | Reduces space, enables action |
| **Explore** | *branch* | Open multiple starts; compare, abandon, return | Multiplication without commitment |
| **Prototype** | *commit* | Make the first mark | Irreversible; all subsequent marks constrained |
| **Research** | *defer* | "Not ready yet" — wait for clarity | May never begin |
| **Incubate** | *suspend* | Let ideas form in the potential | Requires patience |
| **Scope** | *widen* | All blank pages; the space of all beginnings | Goes meta; still haven't started |

**Blocked moves**:
- *Complete* — nothing to complete yet

## Strategy Space

### Path A: Constrain to enable
```
Blank → constrain genre → constrain audience → action space manageable → begin
```
**Payoff**: Restriction enables decision. Fewer options = possible action.

### Path B: Prototype immediately
```
Blank → make any mark → momentum starts → revise later
```
**Payoff**: Perfect is enemy of done. Start messy.

### Path C: Formal constraint
```
Blank → adopt constraint → "sonnet, lipogram, prompt" → freedom through limit
```
**Payoff**: Oulipo strategy. The rule generates.

### Path D: Defer indefinitely (antipattern)
```
Blank → "not ready" → research more → "still not ready" → never begin
```
**Payoff**: Negative. Preparation becomes procrastination.
