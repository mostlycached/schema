# Absolute Zero

## The Site

-273.15°C. 0 Kelvin. The temperature at which molecular motion ceases. Not "very cold" — the theoretical floor of cold. Below this, there is no below. We can approach it asymptotically: laboratories have reached billionths of a degree above. But reaching it exactly is forbidden by thermodynamics. The limit that can never be touched.

**Dimensions**:
```
ontological: limit (thermodynamic minimum)
scale: fundamental (applies everywhere)
temporal: asymptotic (approach forever, never arrive)
perceptual: theoretical (no human experience possible)
relational: objective (independent of observer)
agential: none (no activity at absolute zero)
structural: limit (boundary that cannot be crossed)
```
