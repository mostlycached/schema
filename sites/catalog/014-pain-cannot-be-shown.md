# The Pain That Cannot Be Shown

**Practice**: Contemplation

---

## State Space

You are in **the privacy of qualia** — the solitude of suffering.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Reality | Undeniable | The pain is real |
| Access | BLOCKED | Others cannot enter |
| Communication | Failed | Can assert but not prove |

**Tension**: Variable (pain level) + constant (isolation).

---

## Action Set

In **Contemplation** practice, your moves are private-experience operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Endure** | *hold* | Bear the pain alone | Stoic isolation |
| **Attend** | *focus* | Notice the pain directly | May intensify |
| **Describe** | *attempt* | Try to find words | Words fail |
| **Generalize** | *notice* | All inner experience is private | Goes abstract |

**Blocked moves**:
- *Complete* — cannot show; cannot bridge
- *Engage* — can't share access

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Hold → endure alone** | +stability | Stoic isolation |
| **Focus → attend to pain** | +awareness | Attention may intensify |
| **Narrow → words** | +attempt | Language fails; it's like... but not |
| **Narrow → metaphor** | +indirection | Comparison as approximation |
| **Expand → all inner experience** | +philosophical | Joy equally private |

## Global Operations

| Operation | Contemplative Consequence |
|-----------|--------------------------|

| **TRANSFER** | Maps to: black box (sealed), foreign language (untranslatable), island (isolated), courtroom (testimony) |
| **DISSOLVE** | Pain may dissolve (healing); privacy never dissolves |
| **EMERGE** | Art, isolation, or a scream |

## Strategy Space

### Path A: Endure (stoic)
```
Pain → can't show → endure alone → isolation as given
```
**Payoff**: Stability through acceptance of aloneness.

### Path B: Attempt description
```
Pain → try words → "it's like..." → fails → back to solitude
```
**Payoff**: Reveals the gap through failure.

### Path C: Generalize
```
Pain → all inner experience → qualia problem → everyone is private
```
**Payoff**: Philosophical company; shared isolation.

### Path D: Metaphor
```
Pain → "like burning" → not exactly → indirection as best available
```
**Payoff**: Approximate communication; never direct.
