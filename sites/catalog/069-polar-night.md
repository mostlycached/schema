# The Polar Night

**Practice**: Contemplation

---

## State Space

You are in **temporal suspension** — the ancient cycle of light and dark has ceased.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Duration | Months | The sun does not rise |
| Temporal | Collapsed | Day/night distinction gone |
| Certainty | Total | The sun WILL return |

**Tension**: Chronic-low-endurance. Time loses grip; starlight persists.

---

## Action Set

In **Contemplation** practice, your moves are endurance operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Endure** | *suspend* | Dwell in the darkness; wait | Months of waiting |
| **Expand** | *widen* | Everyone here shares this; planetary cause | Universalizes |
| **Adapt** | *branch* | Artificial light; fill darkness with activity | Compensatory |
| **Examine** | *speculate* | What does endless night do to the mind? | Opens psychology |

**Blocked moves**:
- *Complete* — cannot make the sun rise

## Strategy Space

### Path A: Endurance (default)
```
Sun gone → suspend → wait → endure → months pass → sun returns
```
**Payoff**: The polar night as training in patience. Dawn earned.

### Path B: Adaptation
```
Sun gone → artificial light → activity → darkness becomes managed
```
**Payoff**: Modern solution. Darkness domesticated.

### Path C: Contemplative depth
```
Sun gone → what does this reveal? → time without sun → mind adapts
```
**Payoff**: Insight into light-dependence. Existential depth.

### Path D: Anticipation
```
Sun gone → await return → the first sunrise after months → sublime
```
**Payoff**: Maximum contrast. Light never so valued.
