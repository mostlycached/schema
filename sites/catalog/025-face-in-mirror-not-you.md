# The Face in the Mirror That Isn't You

**Practice**: Contemplation

---

## State Space

You are in **recognition failure** — self split from image.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Knowledge | It's you | You know this is your reflection |
| Experience | Stranger | The face looking back is unfamiliar |
| Ontology | Both true | Self and not-self simultaneously |

**Tension**: Medium-high. Uncanny oscillation.

---

## Action Set

In **Contemplation** practice, your moves are attention operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Dwell** | *hold* | Stay in the split | Dissociation intensifies |
| **Examine** | *focus* | What exactly is strange? | May not find answer |
| **Generalize** | *notice* | All self-perception is like this | Goes abstract |
| **Exit** | *release* | Look away; break the gaze | Escape without insight |

**Blocked moves**:
- *Complete* — can't resolve the split; both are true

## Strategy Space

### Path A: Dwell in split
```
See stranger → stay in split → experience the uncanny → dissociation held
```
**Payoff**: The experience itself as insight into identity.

### Path B: Analyze
```
See stranger → examine features → "what exactly is wrong?" → may not find answer
```
**Payoff**: Investigation may or may not resolve.

### Path C: Generalize
```
See stranger → "all self-perception" → recognition as achievement → sublime
```
**Payoff**: This moment reveals identity as constructed.

### Path D: Escape
```
See stranger → look away → break gaze → recognition returns
```
**Payoff**: Relief but no insight.
