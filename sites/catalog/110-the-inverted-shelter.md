# The Inverted Shelter

**Practice**: Architecture
**Operation**: `Nesting(Within(PROTECTION, EXPOSURE))`
**Constraint**: The structure protects you from the world *specifically so you can be exposed* to a curated interior danger. The shelter is a lens for focusing exposure.

---

## State Space

You are in **the focusing machine** — the walls do not block the wind; they channel it.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Walls | Focusing | Funnel exterior forces (light/cold) into beams |
| Geometry | Hostile | Angles reject the resting body (no flat floors) |
| Function | Exposure | Maximum vulnerability to the curated element |
| Interior | Trap | You cannot leave, but you are not safe |

**Tension**: Ascetic (Comfort is the enemy; sensation is the goal).

---

## Action Set

In **Architecture** practice, moves are inverted by the goal of exposure:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Inhabit** | *commit* | Enter the focal point | Overexposure / Hypothermia |
| **Renovate** | *block* | Try to add insulation | The house rejects the addition |
| **Hide** | *branch* | Find a corner | The geometry slides you back to center |
| **Design** | *narrow* | Sharpen the focus | Making the torture more efficient |

**Blocked moves**:
- *Rest* — no flat surfaces
- *Shelter* — definitionally impossible here

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Inhabit → endure** | +sensation | The body hardens or breaks |
| **Renovate → fail** | +frustration | The realization of the machine's purpose |
| **Hide → slide** | +participation | You become the ball in the game |
| **Transfer → ×monastery** | +frame | Spiritual exposure |
| **Transfer → ×prison** | +frame | Punitive exposure |
| **Transfer → ×stadium** | +frame | Exposure to the gaze |

## Global Operations

| Operation | Mutated Consequence |
|-----------|--------------------|
| **GENERATE** | Produces: "panopticons", "isolation tanks", "ascetic cells", "torture gardens" |
| **TRANSFER** | Maps to: institutional design (hostile architecture), religious architecture (stylites), modernism (glass houses) |
| **DISSOLVE** | Through destruction of the lens (ruin) |
| **PARASITIZE** | The HVAC intercepts the focus; climate control fights the lens, normalizing the temperature |
| **EMERGE** | A callus, a saint, or a corpse |

## Strategy Space

### Path A: The Ascetic
```
Enter → submit to focus → endure cold/light → body breaks → spirit clarifies
```
**Payoff**: Transcendence through suffering.

### Path B: The Renovator
```
Enter → feel cold → build wall → wall slides away → fight the house → exhaustion
```
**Payoff**: The infinite battle against the design.

### Path C: The Specimen
```
Enter → be seen → the walls are lenses → the world watches → performance
```
**Payoff**: Total visibility; loss of privacy.
