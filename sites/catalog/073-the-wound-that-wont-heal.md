# The Wound That Won't Heal

**Practice**: Contemplation

---

## State Space

You are at **the failed contract** — damage without repair.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontological | Process | Failed repair |
| Duration | Indefinite | Weeks/Months |
| Redemption | Zero | No lesson learned |
| Cleanup | Infinite | Recursive tending |

**Tension**: Oscillating (better/worse, never resolved).

---

## Action Set

In **Contemplation** practice, your moves are endurance operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Tend** | *suspend* | Clean, dress, wrap | Futility |
| **Inspect** | *witness* | Seeing the ooze | Disgust |
| **Hope** | *defer* | "Maybe tomorrow" | Disappointment |
| **Accept** | *resolve* | Living with the breach | Resignation |

**Blocked moves**:
- *Heal* — biological failure
- *Ignore* — somatic insistence (pain/wetness)

| Operation | Contemplative Consequence |

## Strategy Space

### Path A: The Hopeful
```
Tend → Hope → Disappointment → Tend
```
**Payoff**: Sustaining the illusion of repair.

### Path B: The Resigned
```
Tend → Accept → Incorporate wound → Live with leakage
```
**Payoff**: Honest embodiment; reduced anxiety.

### Path C: The Abject
```
Inspect → Focus on ooze → "I am rotting" → Confront mortality
```
**Payoff**: Ontological vertigo; facing the end.
