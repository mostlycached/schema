# The Sound That Hurts

**Practice**: Contemplation

---

## State Space

You are at **auditory assault** — the frequency that cuts.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontological | Intrusion | Vibration |
| Quality | Pain | Screech/Grind |
| Agency | Victim | Cannot close ears |
| Duration | Now | Immediate |

**Tension**: Neural (Signal vs. Tolerance).

---

## Action Set

In **Contemplation** practice, your moves are shield operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Block** | *mask* | Cover ears | Hands occupied |
| **Flee** | *branch* | Leave area | Disruption |
| **Tense** | *suspend* | Bracing | Muscle pain |
| **Identify** | *narrow* | "What is that?" | Focus on pain |

**Blocked moves**:
- *Close* — ears have no lids
- *Tune out* — signal too strong

## Strategy Space

### Path A: The Reflex
```
Sound -> Wince -> Hands to ears -> Curl
```
**Payoff**: Instinctive protection.

### Path B: The Rage
```
Sound -> Irritation -> Identify source -> "Shut up!"
```
**Payoff**: Externalizing the pain.

### Path C: The Endurer
```
Sound -> Tense muscles -> Wait it out -> "It will pass"
```
**Payoff**: Stoic suffering; high cost.
