# The Thing That Hasn't Happened Yet

**Practice**: Writing

---

## State Space

You are **living in the approach** — the event hasn't arrived but is coming.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontology | Virtual | Not yet actual |
| Probability | High | Weight of approach |
| Resolution | BLOCKED | Can't address what hasn't arrived |

**Tension**: High but sustained. Anticipatory dread.

---

## Action Set

In **Writing** practice, your moves are narrative anticipation operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Defer** | *postpone* | Another day of waiting | Tension preserved |
| **Hold** | *suspend* | Accept without resolution | Live in the not-yet |
| **Prepare** | *narrow* | What can I do before it arrives? | Action as control |
| **Grieve** | *probe* | Anticipatory mourning | Grief before loss |

**Blocked moves**:
- *Complete* — it hasn't happened; can't resolve

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Defer → "not yet"** | +preservation | Another day of waiting |
| **Defer → each day** | +tragic dwelling | Living in the not-yet; present colonized |
| **Suspend → hold open** | +acceptance | Neither resolved nor escaped |
| **Narrow → prepare** | +action | Practical arrangements |
| **Narrow → emotional** | +early grief | Anticipatory mourning |
| **Widen → everyone waiting** | +normalization | "Everyone is waiting for something" |
| **Commit → prepare** | +agency | Acting despite uncertainty |
| **Transfer → ×weather** | +frame | Approaching storm |
| **Transfer → ×pregnancy** | +frame | Carrying what hasn't arrived |

---

## Global Operations

| Operation | Narrative Consequence |
|-----------|----------------------|
| **GENERATE** | Produces: "waiting for test results", "the parent who is dying", "before the wedding" |
| **TRANSFER** | Maps to: weather (storm), pregnancy (carrying), execution (scheduled doom), illness (prognosis) |
| **DISSOLVE** | When event arrives, event averted, or certainty collapses |
| **EMERGE** | The event itself (relief/horror), or the realization it won't happen |

## Strategy Space

### Path A: Defer (default)
```
Approaching → "not yet" → another day → tension preserved
```
**Payoff**: Live another day before it arrives.

### Path B: Prepare
```
Approaching → "what can I do?" → arrangements → action as control
```
**Payoff**: Agency; preparation that may not prevent.

### Path C: Anticipatory grief
```
Approaching → grieve now → mourning before loss → suffer twice or process early
```
**Payoff**: Emotional preparation at cost of present experience.

### Path D: Accept
```
Approaching → suspend → live in the not-yet → neither resolve nor escape
```
**Payoff**: Presence with uncertainty.

## Position Summary

```
Where you are:   Living in the approach; the thing hasn't arrived but is coming
What you hold:   Probability + weight + inability to resolve
What blocks you: Can't prevent, can't resolve, must wait
Best moves:      Defer (another day) or Suspend (accept uncertainty)
Dominant affect: Tragic-uncanny — anticipatory dread
```
