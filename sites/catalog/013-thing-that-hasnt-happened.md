# The Thing That Hasn't Happened Yet

## The Site

You know it's coming. Not with certainty — but with the heavy weight of probability. The diagnosis that hasn't been confirmed. The conversation that hasn't happened. The loss that's approaching but hasn't arrived.

**Dimensions**:
```
ontological: virtuality (but approaching actuality)
scale: variable (days to years)
temporal: anticipation
perceptual: peripheral + somatic (felt in body, seen at edges)
relational: variable
agential: anyone
structural: incomplete (the event is not yet whole)
```
