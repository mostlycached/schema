---

## State Space

You are at **reconstructed hygiene** — the smallest kinesphere.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Scale | Sub-personal | Kinesphere only |
| Frame | Dissolved | Hygiene → Movement |
| Privacy | Maximum | Solitary confinement |

**Tension**: Low (habitual) → High (exploratory).

## Action Set

In **Design** practice, your moves are reconstruction operations (Laban Grammar):

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Dissolve** | *dissolve* | Hygiene frame -> Movement frame | Loss of utility |
| **Space** | *reframe* | Direct/Indirect bathing | Inefficiency |
| **Weight** | *prototype* | Strong/Light water interaction | Unfamiliar sensation |
| **Time** | *structure* | Quick/Sustained washing | Late for work |
| **Flow** | *iterate* | Bound/Free movement | Slipping |

**Blocked moves**:
- *Optimize* — kills exploration
- *Routine* — re-establishes hygiene frame

## Strategy Space

### Path A: The Laban Shower
```
Dissolve frame → Apply Effort (Weight/Time/Space/Flow) → Choreograph wash
```
**Payoff**: Routine becomes research.

### Path B: The Affective Shower
```
Reframe → Shape (Rising/Sinking) → Generate emotion through form
```
**Payoff**: Somatic regulation.

### Path C: The Environment Prototype
```
Prototype → Dark shower / Cold shower / Floor shower → Sensory limit
```
**Payoff**: Environmental design data.
