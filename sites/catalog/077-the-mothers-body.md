# The Mother's Body

**Practice**: Contemplation

---

## State Space

You are at **the abject origin** — the body you had to reject to be.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontological | Origin | Primal source |
| Relation | Split | Merged → Rejected |
| Affect | Ambivalent | Need + Disgust |
| Time | Cyclical | Returns in death/aging |

**Tension**: Foundational (cannot fully separate, cannot fully return).

---

## Action Set

In **Contemplation** practice, your moves are origin operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Recall** | *witness* | The primal bond | Regression |
| **Reject** | *branch* | Assert separation | Guilt |
| **Merge** | *suspend* | Return to source | Psychosis/Death |
| **Analyze** | *speculate* | Kristeva's theory | Intellectualization |

**Blocked moves**:
- *Resolve* — you are always of this body
- *Erase* — it is your substrate

## Strategy Space

### Path A: The Rejection (Developmental)
```
Born -> Need -> Reject -> Become Self -> Visit occasionally
```
**Payoff**: Successful subjectivity; repression of origin.

### Path B: The Return (Regression)
```
Fail -> Seek comfort -> Merge -> Loss of boundary
```
**Payoff**: Safety; loss of self.

### Path C: The Analysis (Kristeva)
```
Recognize abjection -> Understand the horror -> Accept the debt
```
**Payoff**: Conscious relationship with origin.
