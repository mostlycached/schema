# The Warmth of a Recently Vacated Seat

**Practice**: Contemplation

---

## State Space

You are in **thermal trace** — presence as residue.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Trace | Body heat | Fading fast |
| Identity | Unknown | Who was just here? |
| Duration | Brief | Entropy wins soon |

**Tension**: Low-medium. Uncanny but not threatening.

---

## Action Set

In **Contemplation** practice, your moves are somatic attentions:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Dwell** | *hold* | Rest in the strangeness | Warmth fading |
| **Investigate** | *focus* | Who was just here? | May never know |
| **Generalize** | *notice* | All such traces | Universal pattern |
| **Ignore** | *defer* | Sit anyway | Normalize the strangeness |

**Blocked moves**:
- *Complete* — can't resolve the intimacy
- *Release* — the warmth is already releasing itself

## Strategy Space

### Path A: Dwell in uncanny
```
Sit → warm → notice → dwell in strangeness → thermal intimacy
```
**Payoff**: Experience the trace before it fades.

### Path B: Investigate
```
Sit → warm → "who?" → look around → identify or fail
```
**Payoff**: Reduces strangeness if source found.

### Path C: Generalize
```
Sit → warm → "all traces" → towels, beds, cups → bodies are porous
```
**Payoff**: This trace as instance of pattern.

### Path D: Normalize
```
Sit → warm → ignore → just sit → strangeness dissolves unremarked
```
**Payoff**: Convenient but misses the experience.
