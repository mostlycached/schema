# The Cowardice You Showed

**Practice**: Philosophy

---

## State Space

You are at **moral limit** — the failure of character.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontological | Act | Non-action (Refusal) |
| Reason | Fear | Self-preservation |
| Knowledge | Full | You knew better |
| Status | Fixed | Cannot undo |

**Tension**: Permanent (Memory of failure).

---

## Action Set

In **Philosophy** practice, your moves are moral operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Confess** | *witness* | Admit fault | Shame |
| **Rationalize** | *speculate* | "I couldn't help" | Self-deception |
| **Forget** | *suspend* | Suppress memory | Unconscious guilt |
| **Atone** | *commit* | Try again later | Too late for *that* moment |

**Blocked moves**:
- *Undo* — time arrow
- *Excuse* — you knew

## Global Operations

| Operation | Philosophical Consequence |
|-----------|--------------------------|
| **GENERATE** | Produces: "regret", "moral injury", "cynicism", "caution" |
| **TRANSFER** | Maps to: tragedy (hamartia), ethics (akrasia), psychology (fight/flight) |
| **DISSOLVE** | Through forgiveness (rare) or total forgetting |
| **PARASITIZE** | The Disclaimer intercepts the guilt; "I was protecting my boundaries" reframes fear as self-care |
| **EMERGE** | A lie, a lifelong shame, or a specific silence |

## Strategy Space

### Path A: The Lie
```
Run away -> "I did my best" -> Believe it -> Weakness spreads
```
**Payoff**: Integrity simulation; character rot.

### Path B: The Guilt
```
Run away -> "I failed" -> Replay loop -> Paralysis
```
**Payoff**: Punishment; no growth.

### Path C: The Truth
```
Run away -> "I was afraid" -> Accept fragility -> Watchfulness
```
**Payoff**: Humility; watchful waiting.
