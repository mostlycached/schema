# The Life You Almost Lived

**Practice**: Writing

---

## State Space

You are in **counterfactual narrative** — a parallel story that exists as permanent ghost alongside the actual.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontology | Virtual | Real enough to mourn, never existed |
| Temporal | Ongoing | Past fork, present haunting |
| Access | Peripheral | Glimpsed, never directly seen |

**Tension**: Low-chronic melancholy. The ghost-life accompanies you.

---

## Action Set

In **Writing** practice, your moves are narrative operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Pose question** | *suspend* | Hold the virtual open, live alongside | Permanent haunting |
| **Expand scope** | *introduce* | All the lives almost lived | Overwhelm into paralysis |
| **Specify detail** | *narrow* | Focus on one fork, one person-you-would-have-been | May intensify mourning |
| **Open new possibilities** | *branch* | A new fork now — present not settled | May multiply ghosts |

**Blocked moves**:
- *Reveal* — cannot actualize the ghost
- *Conclude* — cannot dismiss it either

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Suspend → "live alongside"** | +coexistence | Ghost becomes companion |
| **Suspend → comfort** | +consolation | "It would have had problems too" |
| **Suspend → torment** | +tragic depth | Ghost becomes accuser |
| **Narrow → "who would I have been?"** | +character depth | The other-you becomes vivid |
| **Narrow → "that one decision"** | +plot clarity | The fork is named |
| **Expand → "all almost-lives"** | +sublime scope | You are one branch of infinite tree |
| **Branch → "new fork now"** | +agency | Present becomes open again |
| **Transfer → ×ghost** | +frame | "Haunted by the unlived" |
| **Transfer → ×quantum** | +cosmic | "All branches exist somewhere" |

---

## Global Operations

| Operation | Narrative Consequence |
|-----------|----------------------|
| **GENERATE** | Produces: "the person you didn't marry", "the career you abandoned", "if you had stayed" |
| **TRANSFER** | Maps to: ghost (haunting), shadow (cast by actual), quantum (many-worlds), fiction (unwritten story) |
| **DISSOLVE** | Slow: requires radical acceptance or replacement satisfactions |
| **PARASITIZE** | The Fantasy intercepts the grief; you prefer the perfect ghost to the flawed reality |
| **EMERGE** | Acceptance of the singular life, or a renovated present |

---

## Strategy Space

### Path A: Companionship (default)
```
Ghost-life → accept coexistence → live alongside → melancholic peace
```
**Payoff**: The ghost becomes gentle. You live with both.

### Path B: Specification
```
Ghost-life → "that decision" → "who I would have been" → detailed portrait
```
**Payoff**: The ghost becomes character. Vivid but fixed.

### Path C: Expansion
```
Ghost-life → "all almost-lives" → infinite branching → sublime vertigo
```
**Payoff**: This life revealed as one of infinite possibilities.

### Path D: Present reclamation
```
Ghost-life → "there's a fork NOW" → agency returns → new story begins
```
**Payoff**: Past ghost yields to present possibility.
