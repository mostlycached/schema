# The Blind Ascent

**Practice**: Sociology / Somatic
**Operation**: `Negation(NOT(VISUAL))`
**Constraint**: The sublime is present, but the visual channel is deleted.

---

## State Space

You are **climbing a monster in the dark** — the volcano exists only as heat, vibration, and smell.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Vision | Zero | Pitch black / Blindness |
| Heat | Gradient | Navigation by temperature |
| Sound | Roar | Orientation by volume |
| Touch | Dyadic | Hand-on-shoulder link |

**Tension**: Somatic (The world is too close).

---

## Action Set

Moves are re-mapped to non-visual channels:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Palpate** | *narrow* | Feel the rock/path | Burns |
| **Listen** | *widen* | Map the void by echo | Disorientation |
| **Link** | *connect* | Physical chain with other | Falling together |
| **Smell** | *focus* | Detect sulfur (danger) | Overwhelm |

**Blocked moves**:
- *Look* — impossible
- *Project* — impossible (can't see distance)
- *Scope* — impossible (world is arm-length)

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Palpate → heat** | +warning | "Too close" (pure data) |
| **Link → drag** | +unity | One body, four legs |
| **Listen → echo** | +space | The void imagined |
| **Transfer → ×cave** | +frame | The underground |
| **Transfer → ×blind** | +frame | Disability as mode |
| **Transfer → ×night** | +frame | The primal dark |

## Global Operations

| Operation | Operational Consequence |
|-----------|------------------------|
| **GENERATE** | Produces: "echolocation", "haptic languages", "trust walks", "night terrors" |
| **TRANSFER** | Maps to: deep ocean (no light), womb (pre-visual), sleep (dreaming) |
| **DISSOLVE** | Sunrise (if physical) or Sight restoration |
| **PARASITIZE** | The GPS intercepts the dark; the blue dot tells you where you are, removing the need to feel the rock |
| **EMERGE** | Echolocation, night vision, or a broken climber |

---

## Strategy Space

### Path A: The Symbiote
```
Blindness → link bodies → move as one → shared proprioception → survival
```
**Payoff**: Loss of self-boundary; effective navigation.

### Path B: The Scanner
```
Blindness → use heat as vision → "brighter = hotter = danger" → thermal navigation
```
**Payoff**: New sense modality.
