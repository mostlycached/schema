**Practice**: Music

---

| Dimension | Value | Constraint |

| Process | Dissolution-active | Meaning un-accumulates |
| Sound | Persists | Phonetics remain |
| Meaning | Gone | The void where content was |

## Strategy Space

### Path A: Dwell in dissolution
```
Word repeated → meaning goes → hold the void → uncanny
```
**Payoff**: Experience the arbitrariness of the sign directly.

### Path B: Analyze the phonetics
```
Word repeated → meaning goes → "what IS this sound?" → pure form
```
**Payoff**: Sound without meaning — linguistic decomposition.

### Path C: Universalize
```
Word repeated → meaning goes → "all words are like this" → semiotic insight
```
**Payoff**: The sign as arbitrary, felt not merely known.

### Path D: Test recovery
```
Word repeated → meaning goes → try to mean it → does it return?
```
**Payoff**: Usually yes — meaning is maintenance, not permanent.
