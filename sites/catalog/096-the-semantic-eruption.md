**Practice**: Linguistics
**Speculation**: Cross-Domain (Linguistics × Volcanology)

---

## State Space

You are at **the semiotic rupture** — where meaning liquefies and overflows structure.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Flow | Hyper-semantic | Meaning exceeds containment |
| Temperature | "Hot" meaning | Dangerous to handle directly |
| Stability | Ruptured | Syntax cannot hold semantics |
| Scale | Discourse | Affects entire language field |

**Tension**: Extreme (communicative capability vs. semiotic overload).

## Action Set

In **Linguistics** practice, your moves are modified by the fluid state of meaning:

| Move | Verb | Effect | Risk |

## Strategy Space

### Path A: The Poet (Channel)
```
Rupture → ride the flow → shape while hot → new meaning
```

### Path B: The Dogmatist (Crystallize)
```
Rupture → fear chaos → rapid cooling → rigid text
```
**Payoff**: Safety; brittle structure; dead language.

```
Rupture → stand at edge → let language fail → pure experience
```
**Payoff**: Transcendence; loss of communicability.

### Path D: The Censor (Dam)
```
Rupture → suppress → enforce silence → pressure builds
```
**Payoff**: Temporary order; inevitable catastrophe.
