# The Irreversible Act

**Practice**: Philosophy

---

## State Space

You are **after the act that cannot be undone** — living forward only.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Reversibility | Zero | Cannot be undone |
| Stakes | Maximum | Permanent consequence |
| Identity | Transformed | You are now one who did this |

**Tension**: Varies (relief to horror to acceptance).

---

## Action Set

In **Philosophy** practice, your moves are post-factum operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Accept** | *suspend* | Living with what's done | Permanent |
| **Trace** | *narrow* | What follows from this? | Consequences unfold |
| **Generalize** | *widen* | All irreversible acts | Goes abstract |
| **Proceed** | *branch* | What can be done now? | Forward only |

**Blocked moves**:
- *Undo* — impossible by definition
- *Complete* — can't resolve what's done

## Strategy Space

### Path A: Accept
```
Act done → can't undo → suspend → live with it
```
**Payoff**: Tragic acceptance; forward only.

### Path B: Trace consequence
```
Act done → can't undo → what follows? → effects unfold
```
**Payoff**: Understanding implications.

### Path C: Proceed
```
Act done → can't undo → what now? → new action
```
**Payoff**: Forward motion; making the best of it.

### Path D: Deny (fails)
```
Act done → pretend not → fails → back to acceptance
```
**Payoff**: Temporary defense; eventual reckoning.
