# The Micro-Volcano

**Practice**: Design
**Constraint**: `scale = micro` (The same physics at trivial scale)

---

## State Space

You are at **the point of tiny heat** — the solder tip, the match head, the pimple.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Temperature | High | Burns skin, not cities |
| Scale | Millimeter | Requires lens/focus |
| Control | High | You are the god of this volcano |
| Duration | Seconds | Quick eruption/cooling |

**Tension**: Low (Playful / Precise).

---

## Action Set

In **Design** practice, your moves are precision operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Initiate** | *trigger* | Strike the match / Melt the solder | Minor burn |
| **Observe** | *witness* | Watch the flux at small scale | Eye strain |
| **Apply** | *transfer* | Use the heat to join/change | Damage component |
| **Extinguish** | *block* | Pinch it out | residue |

**Blocked moves**:
- *Fear* — scale makes it safe
- *Run* — unnecessary

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Trigger → watch** | +fascination | "Fire is beautiful when small" |
| **Apply → join** | +utility | Circuit connected |
| **Apply → burn** | +sadism | Ant destroyed; small cruelty |
| **Extinguish → control** | +power | "I can stop this" |
| **Transfer → ×pimple** | +frame | Somatic micro-eruption |
| **Transfer → ×anger** | +frame | Brief flair-up |
| **Transfer → ×match** | +frame | Promethean spark |

---

## Global Operations

| Operation | Constrained Consequence |
|-----------|------------------------|
| **GENERATE** | Produces: "soldering", "welding", "popping a pimple", "lighting a cigarette" |
| **TRANSFER** | Maps to: nanotechnology (handling atoms), surgery (micro-intervention), anger management (small outbursts) |
| **DISSOLVE** | Rapid cooling; blowing it out |
| **EMERGE** | Molten solder, a burnt finger, or a sterile needle |

---

## Strategy Space

### Path A: The Technician
```
Heat source → target point → melt → join → cool → structure built
```
**Payoff**: Construction through controlled destruction.

### Path B: The Sadist
```
Micro-eruption → apply to living thing (bug) → watch destruction → god complex
```
**Payoff**: Power fantasy at safe scale.

### Path C: The Groomer
```
Pressure builds (skin) → locate → squeeze → eruption → relief
```
**Payoff**: Abject satisfaction; hygiene.
