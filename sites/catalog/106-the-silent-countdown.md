# The Silent Countdown

**Practice**: Sociology / Contemplation
**Base**: `dyadic` + `danger` + `enclosed` + `countdown`
**Layer 3**: `gestural = blocked(COMMUNICATE)` (Silence/Masks/Noise)

---

## State Space

You are **bodies processing end-times** — meaning must occur without words.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Sound | Deafening | Eruption/Noise drowns speech |
| Mouth | Covered | Gas mask / Respirator |
| Contact | Eye/Touch | Only channels left |
| Interior | Loud | Thoughts scream |

**Tension**: Hyper-Critical (The limit of the human).

---

## Action Set

Moves are reduced to physical semiotics:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Grip** | *connect* | Squeeze hand | Ambiguous (fear? love?) |
| **Stare** | *witness* | Lock eyes | Terrifying intimacy |
| **Turn** | *block* | Face the wall | Rejection (final) |
| **Share** | *resolve* | Pass the mask | Performance of sacrifice |

**Blocked moves**:
- *Speak* — impossible
- *Explain* — impossible
- *Lie* — harder without words (body tells truth)

## Strategy Space

### Path A: The Gaze
```
Noise rises → speech fails → lock eyes → witness the other witnessing me → death
```
**Payoff**: Recursive consciousness loop.

### Path B: The Touch
```
Noise rises → close eyes → hold hand → pulse as only signal → fade
```
**Payoff**: Somatic continuity.

### Path C: The Struggle
```
Noise rises → panic → fight for mask → primal violence → guilt/death
```
**Payoff**: Survival of the fittest body.
