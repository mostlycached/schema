## Strategy Space

### Path A: The Cover-Up
```
Forget -> Excuse -> Hide -> Pretend
```
**Payoff**: Temporary dignity; high anxiety.

### Path B: The Witness
```
Forget -> Notice -> Record -> "I am leaving"
```
**Payoff**: Tragic clarity; conscious exit.

### Path C: The Fade
```
Forget -> Don't notice -> Forget more -> Gone
```
**Payoff**: Blissful ignorance; absence.
