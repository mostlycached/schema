## Action Set

In **Mathematics** practice, your moves are logical operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Generalize** | *remove hypotheses* | Extend to all necessary truths | Loses specificity |
| **Specialize** | *add hypotheses* | Focus on 2+2=4 specifically | Loses scope |
| **Conjecture** | *pose open problem* | "What IS this truth?" — ontological question | May be unanswerable |
| **Consider cases** | *branch* | Platonism vs. formalism vs. intuitionism | Multiplies positions |
| **Derive** | *prove* | Show this truth follows from axioms | Doesn't explain the axioms |

**Blocked moves**:
- *Assert* — nothing to assert; it's already true
- *Complete* — already complete; nothing to prove
- *Dissolve* — impossible; infinite resistance

### Path A: Contemplative dwelling
```
2+2=4 → contemplate → it cannot be otherwise → sublime rest
```
**Payoff**: Mathematical truth as meditation object. Stability as comfort.

### Path B: Ontological inquiry
```
2+2=4 → "what IS this truth?" → Platonism vs. formalism → metaphysical vertigo
```
**Payoff**: The truth exists; but what IS existence for truths?

### Path C: Generalization
```
2+2=4 → all mathematics → all necessary truths → the structure of necessity
```
**Payoff**: This truth as one point in infinite lattice of necessity.

### Path D: Limit case
```
2+2=4 → "could it be otherwise?" → NO → but why not?
```
**Payoff**: The necessity revealed as strange. Why can't it be different?
