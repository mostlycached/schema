# Mathematical Truth

## The Site

2 + 2 = 4. This was true before humans existed. It will be true after the universe ends. It doesn't depend on anyone believing it. It cannot be changed by decree, by force, by time. Mathematical truths are the hardest structures we know — infinitely resistant to dissolution, eternally stable, absolutely invariant.

**Dimensions**:
```

```
