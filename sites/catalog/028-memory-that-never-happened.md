# The Memory That Never Happened

## The Site

You remember it clearly. The place, the people, the feeling. But it didn't happen. The memory is vivid — more vivid than real memories — and completely false. Your brain has confabulated an experience you never had.

**Dimensions**:
```
ontological: virtuality (indistinguishable from actuality internally)
scale: lifetime (the "memory" spans time)
temporal: memory (but of what?)
perceptual: direct (phenomenally identical to real memory)
relational: variable
agential: anyone
structural: paradoxical (real memory, false event)
```
