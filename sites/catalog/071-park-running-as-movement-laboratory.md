# Park Running as Movement Laboratory

**Practice**: Design

---

## State Space

You are at **reconstructed locomotion** — fitness becomes digestion.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Scale | Environmental | Park loop |
| Frame | Reconstructed | Fitness → Digestion/Exploration |
| Mode | Locomotor | Bipdedal typically |

**Tension**: Low (habitual) → Medium (social strangeness).

---

## Action Set

In **Design** practice, your moves are re-choreographing operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Dissolve** | *dissolve* | Fitness frame -> Movement frame | Social shame |
| **Reframe** | *reframe* | Park as alimentary canal | Disgust/Grotesque |
| **Prototype** | *prototype* | Skip, gallop, crawl, roll | Public stares |
| **Map** | *structure* | Terrain as digestive tract | Grotesque meaning |

**Blocked moves**:
- *Optimize* — pace monitoring kills exploration
- *Compete* — social comparison blocks internal sensing

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Dissolve → fitness** | +freedom | Park as movement field |
| **Reframe → digestive** | +strangeness | "Park as gut" |
| **Prototype → gait** | +play | Galloping/Skipping in public |
| **Prototype → terrain** | +response | Hill = struggle, Path = transit |
| **Map → tract** | +meaning | Runner as bolus/waste |
| **Narrow → sensation** | +somatic | Internal peristalsis |
| **Widen → all movement** | +scope | Locomotion as involuntary |

---

## Global Operations

| Operation | Design Consequence |
|-----------|-------------------|
| **GENERATE** | Produces: "commute as digestion", "traffic as peristalsis", "architecture as organ" |
| **TRANSFER** | Maps to: gastroenterology, fluid dynamics, soft robotics, grotesque realism |
| **DISSOLVE** | When "exercise" frame returns |
| **PARASITIZE** | The Segment intercepts the flow; Strava turns the digestive run into a competitive data point |
| **EMERGE** | Exhaustion, a cleared mind, or an injury |

## Strategy Space

### Path A: Locomotor Lab
```
Dissolve fitness → Prototype gaits (skip, gallop) → Terrain response
```
**Payoff**: Joy of movement; breaking social convention.

### Path B: The Digestive Run (Grotesque)
```
Reframe park as gut → Map hills as sphincters/valves → Runner as waste
```
**Payoff**: Radical de-sanitization of exercise; "The Ugly Truth".

### Path C: Laban Analysis
```
Prototype Effort → Weight/Space/Time/Flow → Landscape Score
```
**Payoff**: Technical mastery of movement in environment.
