# The Light That Left Before You Were Born

**Practice**: Contemplation

---

## State Space

You are observing **posthumous transmission** — presence from an absent source.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontology | Disguised absence | Present light, possibly dead source |
| Scale | Cosmic | Light-years of travel time |
| Access | None | Cannot verify what exists now |

**Tension**: Low but deep. Awe, not anxiety.

---

## Action Set

In **Contemplation** practice, your moves are attentional operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Dwell** | *hold* | Rest in cosmic time | Contemplation sustained |
| **Focus** | *narrow* | This particular dead light | Specificity within vastness |
| **Expand** | *notice* | All perception is delayed | Maximum scope |
| **Rest** | *accept* | The phenomenon is stable | Closes inquiry |

**Blocked moves**:
- *Complete* — cannot affect it; only witness

## Strategy Space

### Path A: Contemplative dwell
```
Look up → see light → know source may be dead → hold the paradox
```
**Payoff**: Cosmic contemplation. Awe without resolution.

### Path B: Scale vertigo
```
Look up → how far? → light-years → "I am seeing the past"
```
**Payoff**: Maximum temporal scale felt.

### Path C: Universalize
```
Look up → all perception delayed → even lamp-light → present never directly seen
```
**Payoff**: Present as inaccessible. Everything is archaeology.

### Path D: Haunting frame
```
Look up → star may be dead → ghost → "it haunts its position"
```
**Payoff**: Uncanny personification. Death watching you.
