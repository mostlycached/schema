# The Thing at Peripheral Vision That Vanishes When Looked At

**Practice**: Contemplation

---

## State Space

You are at **attention's paradox** — looking destroys the object.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Perception | Peripheral-only | Direct gaze destroys it |
| Certainty | BLOCKED | Can never know what it was |
| Duration | Momentary | Vanishes upon attention |

**Tension**: Medium. Curiosity vs. preservation.

---

## Action Set

In **Contemplation** practice, your moves are attentional strategies:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Hold peripherally** | *attend-without-focusing* | Keep it in corner | Fragile; may lose |
| **Resist** | *defer* | Don't look directly | Requires patience |
| **Generalize** | *notice* | All peripheral phenomena | Goes abstract |
| **Theorize** | *speculate* | What was it? | Never confirmed |

**Blocked moves**:
- *Focus* — direct attention destroys the object
- *Engage* — approach destroys it

## Strategy Space

### Path A: Peripheral hold
```
See movement → resist looking → hold in corner → maintain the almost-seen
```
**Payoff**: Preserve the experience at cost of verification.

### Path B: Let it go
```
See movement → resist looking → it fades → never know what it was
```
**Payoff**: Accept uncertainty; don't disrupt.

### Path C: Direct look (destroys)
```
See movement → turn to look → vanishes → was never what you thought
```
**Payoff**: Attempt verification; lose the object.

### Path D: Abstract
```
See movement → "all peripheral phenomena" → some truths seen only sideways
```
**Payoff**: General principle: attention distorts.
