## Strategy Space

### Path A: The Mystic
```
Event -> "Everything happens for a reason" -> Cover the void
```
**Payoff**: Anxiety reduction; lie.

### Path B: The Victim
```
Event -> "Why me?" -> Search for cause -> Despair
```
**Payoff**: Narrative attempt; failure.

### Path C: The Absurdist
```
Event -> "No reason" -> Accept chaos -> Live anyway
```
**Payoff**: Lucid courage; no false hope.
