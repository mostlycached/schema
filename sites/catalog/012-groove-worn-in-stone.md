# The Groove Worn in Stone

**Practice**: Engineering

---

## State Space

You are observing **distributed load over time** — material failure through accumulated micro-stresses.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Temporal | Trans-lifetime | Centuries of load application |
| Causation | Aggregate | No single cause; collective effect |
| Material | Slow deformation | Stone yields to patient pressure |

**Tension**: Low, contemplative. The process is too slow to observe directly.

---

## Action Set

In **Engineering** practice, your moves are analytical operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Analyze mechanism** | *narrow* | How does stone yield? Friction, pressure, chemistry | Loses wonder |
| **Calculate** | *estimate* | How many footsteps? At what rate? | May be unanswerable |
| **Abstract principle** | *widen* | All wear, all erosion, all accumulative processes | Loses this instance |
| **Observe system** | *suspend* | Watch the process (even though imperceptible) | Static |
| **Model process** | *transfer* | Apply river erosion equations | May not fit |

**Blocked moves**:
- *Complete* — the process has no endpoint while use continues
- *Undo* — wear is irreversible without reconstruction

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Narrow → "how many feet?"** | +quantification | Millions over centuries; scale revealed |
| **Narrow → "depth as measure"** | +data | Groove depth = time integral of use |
| **Narrow → "your foot now"** | +participation | You add to the load; you're data |
| **Widen → all wear patterns** | +systemic view | Brass rails, book spines, worn words |
| **Transfer → river erosion** | +model | Feet as water; stone as riverbed |
| **Transfer → voting** | +aggregate insight | Individual negligible; collective decisive |
| **Transfer → archaeology** | +temporal depth | Use deposits traces; time is sediment |

## Global Operations

| Operation | Engineering Consequence |
|-----------|------------------------|
| **GENERATE** | Produces: "path worn through grass", "stairs worn at center", "brass rail worn bright" |
| **TRANSFER** | Maps to: river (erosion), voting (aggregate), archaeology (sediment), language (worn words) |
| **DISSOLVE** | Requires destruction of substrate or counter-process |
| **PARASITIZE** | The Tourist's Foot intercepts the history; erasing the specificity of the Pilgrim's Step |
| **EMERGE** | A replaced step, a structural failure, or the museum frame |

## Strategy Space

### Path A: Quantitative analysis
```
Groove → estimate load → calculate cycles → depth = ∫ pressure dt
```
**Payoff**: Scientific grip on the phenomenon. Numbers give scale.

### Path B: Systems thinking
```
Groove → generalize → all wear → "everything worn by use"
```
**Payoff**: Principle extraction. This is one instance of universal process.

### Path C: River model
```
Groove → ×river → feet as water, stone as bed → erosion dynamics
```
**Payoff**: Powerful analogy. Patient forces exceed acute ones.

### Path D: Participation
```
Groove → "your foot now" → you contribute → you are data point in centuries
```
**Payoff**: Intimacy. You join the anonymous succession.
