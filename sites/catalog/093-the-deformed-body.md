| Dimension | Value | Constraint |

## Action Set

In **Contemplation** practice, your moves are gaze operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|

**Blocked moves**:

- *Beautify* — fails

## Strategy Space

### Path A: The Polite
```
Look -> Look away -> Pretend nothing is wrong -> "Normal"
```
**Payoff**: Social order; denial of reality.

### Path B: The Revulsed
```
Look -> Gag/Recoil -> Leave -> "Gross"
```
**Payoff**: Somatic honesty; cruelty.

### Path C: The Witness
```
Look -> Notice revulsion -> Stay with it -> See person AND body
```
**Payoff**: Complex humanity; hard work.
