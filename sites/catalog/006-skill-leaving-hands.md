# The Skill Leaving Your Hands

## The Site

You try to do something you once did easily. The motion starts — but it's wrong. Slower. Uncertain. The skill is *going*, and you feel it go.

**Dimensions**:
```
ontological: process (specifically: decay)
scale: extended
temporal: accumulation (negative; un-accumulating)
perceptual: somatic + failure-mediated
relational: solitary
agential: expert → intermediate (declining)
structural: incomplete (was composite, losing parts)
```

---

```

dissolution_resistance: low — the site is dissolution
```

This site inverts normal flux dynamics: structure (skill) is dissolving into flux, not emerging from it. The FluxOperation DISSOLVE is the site's nature.
