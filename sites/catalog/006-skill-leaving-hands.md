# The Skill Leaving Your Hands

**Practice**: Engineering

---

## State Space

You are observing **system degradation** — capability decay through disuse or entropy.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Process | Decay | Skill is un-accumulating |
| Direction | One-way | Entropy wins; reversal requires new work |
| Detection | Failure-triggered | You discover loss by failing |

**Tension**: Medium-high grief. The motion starts wrong. You feel it go.

---

## Action Set

In **Engineering** practice, your moves are maintenance operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Diagnose** | *narrow* | What remains? What's lost? | Reveals extent of decay |
| **Maintain** | *practice* | Attempt to slow loss | Practice may reveal decay faster |
| **Defer** | *avoid test* | Schrödinger's skill — don't find out | Postpones but doesn't prevent |
| **Expand** | *generalize* | All capacities fade | Normalizes but doesn't help |
| **Retire** | *suspend* | Stop trying; preserve memory | Gives up without dignity |

**Blocked moves**:
- *Fix* — you can't undo entropy; only slow it or restart

## Strategy Space

### Path A: Denial (defer)
```
Skill decays → don't test → Schrödinger's skill → pretend intact
```
**Payoff**: Temporary comfort. Reality catches up.

### Path B: Maintenance (practice)
```
Skill decays → practice → slow decline? → partial retention OR reveal faster loss
```
**Payoff**: Fighting entropy. Outcome uncertain.

### Path C: Dignified retirement
```
Skill decays → stop trying → preserve memory → the photograph of competence
```
**Payoff**: Trade action for memory. Grief but dignity.

### Path D: Universalize
```
Skill decays → "all capacities fade" → mortality itself → tragic acceptance
```
**Payoff**: Philosophical depth doesn't prevent loss.
