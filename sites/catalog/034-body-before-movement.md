# The Body at Rest Before Movement

**Practice**: Design

---

## State Space

You are at **kinetic potentiality** — all possible movements available.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Degrees of freedom | ~200 | Every joint, muscle available |
| Actions | ~2,100 | Discretized meaningful movements |
| Stillness | Active | Holding, not passive |

**Tension**: Variable (potential energy stored).

---

## Action Set

In **Design** practice, your moves are bodily operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Attend** | *focus* | "What can this body part do?" | Goes granular |
| **Choose type** | *branch* | Functional, expressive, random | Direction commits |
| **Execute** | *prototype* | Any specific movement | Ends stillness |
| **Rest** | *suspend* | Perfect stillness | Holding potential |

**Blocked moves**:
- *Resolve* — stillness doesn't resolve

## Strategy Space

### Path A: Functional movement
```
Rest → what needs doing? → reach, grasp, walk → purpose fulfilled
```
**Payoff**: Useful; directed.

### Path B: Expressive movement
```
Rest → what wants expression? → gesture, dance → meaning made
```
**Payoff**: Meaningful; artistic.

### Path C: Minimal movement
```
Rest → smallest possible → micro-shift → stillness barely disturbed
```
**Payoff**: Subtle; contemplative.

### Path D: Extended stillness
```
Rest → suspend → hold potential → movement stays virtual
```
**Payoff**: Radical presence; energy stored.
