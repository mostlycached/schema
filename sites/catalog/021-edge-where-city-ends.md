# The Edge Where the City Ends

**Practice**: Design

---

## State Space

You are at **the liminal threshold** — where city becomes not-city.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Boundary | Real | There IS an edge |
| Position | FLUX | Edge moves historically |
| Belonging | Neither | Edge belongs to no one |

**Tension**: Low-medium. Contemplative liminality.

---

## Action Set

In **Design** practice, your moves are spatial boundary operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Survey** | *suspend* | Stand at threshold | Liminal dwelling |
| **Specify** | *narrow* | What's here exactly? | Material specificity |
| **Abstract** | *widen* | All boundaries | Generalizes |
| **Cross** | *prototype* | Step over; see what's beyond | Leave the site |

**Blocked moves**:
- *Complete* — edges don't resolve; they move

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Suspend → dwell at threshold** | +liminal depth | Feel both sides simultaneously |
| **Suspend → feel both** | +double presence | City behind, not-city ahead |
| **Narrow → this edge** | +material specificity | What's here: warehouses, lots, scrap? |
| **Narrow → industrial** | +gritty detail | Edge as zone of transitional use |
| **Narrow → natural** | +sublime | City meeting forest/field |
| **Widen → all boundaries** | +abstract scope | This edge as instance of pattern |
| **Branch → cross** | +exploration | Leave the city |
| **Commit → step over** | +action | Position changes |
| **Transfer → ×skin** | +organic frame | City as body |
| **Transfer → ×tide** | +movement frame | Edge advancing/retreating |
| **Transfer → ×membrane** | +permeability | Some things cross, some don't |

---

## Global Operations

| Operation | Design Consequence |
|-----------|-------------------|
| **GENERATE** | Produces: "gentrifying neighborhood", "where wifi stops", "last house before wilderness", "border checkpoint" |
| **TRANSFER** | Maps to: skin (body boundary), tide (movement), membrane (permeability), horizon (visible limit) |
| **DISSOLVE** | Via: development (edge moves), decay (edge retreats), crossing (leave edge behind) |
| **PARASITIZE** | The Suburb intercepts the wild; the edge is paved over with "Nature Close to Home" housing |
| **EMERGE** | A crossing, a new jurisdiction, or a retreat |

## Strategy Space

### Path A: Liminal dwell
```
Reach edge → suspend → feel city behind, not-city ahead → threshold as place
```
**Payoff**: Experience the boundary itself.

### Path B: Material survey
```
Reach edge → what's here? → warehouses, lots, scrub → specific edge-materiality
```
**Payoff**: Concrete rather than abstract experience.

### Path C: Abstract
```
Reach edge → all boundaries → this is a threshold → identity requires edges
```
**Payoff**: General principle derived.

### Path D: Cross
```
Reach edge → step over → leave the city → become something else
```
**Payoff**: Leave the site; position changes.
