# The You They See

**Practice**: Sociology

---

## State Space

You are in **distributed identity** — the gap between self-model and social representation.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Ontology | Relational gap | Same entity, different representations |
| Temporal | Oscillating | Appears in social moments |
| Access | Other-mediated | You see yourself through others' reactions |

**Tension**: Medium-chronic. The You-they-see is a stranger.

---

## Action Set

In **Sociology** practice, your moves are role-analytic operations:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Observe role** | *suspend* | Live with dual identity, accept gap | Permanent alienation |
| **Analyze gap** | *narrow* | Which perspective is wrong? | May find no answer |
| **Map variations** | *widen* | Different audiences, different Yous | Multiplies strangers |
| **Perform adjustment** | *commit* | Become the seen-self or the felt-self | Inauthenticity risk |
| **Suppress** | *defer* | Ignore the gap | Tension persists |

**Blocked moves**:
- *Merge* — you cannot make the perspectives coincide

---

## Payoff Matrix

| Action | Immediate Payoff | Long-term Consequence |
|--------|------------------|----------------------|
| **Suspend → "live with gap"** | +acceptance | Gap becomes durable companion |
| **Defer → "ignore it"** | +short-term stability | Gap resurfaces unexpectedly |
| **Narrow → "they're wrong"** | +self-certainty | Dismisses valid external data |
| **Narrow → "I'm wrong"** | +humility | Destabilizes self-knowledge |
| **Narrow → "neither/both"** | +sophistication | Gap is irreducible |
| **Widen → "everyone has this"** | +normalization | You're not uniquely seen wrong |
| **Commit → "perform for them"** | +social fit | Authenticity cost |
| **Commit → "insist on felt-self"** | +integrity | May be seen as deluded |
| **Transfer → ×mirror** | +frame | Others as distorting surface |

---

## Global Operations

| Operation | Sociological Consequence |
|-----------|-------------------------|
| **GENERATE** | Produces: "your voice on recording", "your reputation", "how they'll describe you at your funeral" |
| **TRANSFER** | Maps to: mirror (reflection), translation (loss in transfer), ghost (haunting), acting (role vs. person) |
| **DISSOLVE** | Rare: requires profound self-knowledge OR complete social alignment |
| **EMERGE** | A reputation, a persona, or social anxiety |

## Strategy Space

### Path A: Accept the gap (default)
```
Gap revealed → suspend → live alongside → dual identity normalized
```
**Payoff**: Mature acceptance of distributed self. The stranger becomes familiar.

### Path B: Analyze the discrepancy
```
Gap revealed → "who's right?" → analyze → discover irreducibility
```
**Payoff**: Understanding without resolution. The gap is structural.

### Path C: Reframe as universal
```
Gap revealed → "everyone has this" → nobody knows themselves → sublime
```
**Payoff**: Problem dissolves into general condition of social existence.

### Path D: Perform toward alignment
```
Gap revealed → "I'll become the seen-self" → performance → alignment achieved?
```
**Payoff**: Social fit at authenticity cost. May feel hollow.

```
Where you are:   In the gap between felt-self and seen-self
What you hold:   Two valid but non-coinciding representations
What blocks you: Cannot merge perspectives; both continue existing
Best moves:      Suspend (accept gap) or Widen (universalize condition)
```
