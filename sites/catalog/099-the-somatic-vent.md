## Strategy Space

### Path A: The Suppressor (Soothe)
```
Heat rises → apply cool/drug → surface calm → deep pressure builds
```
**Payoff**: Functionality; chronic toxicity.

### Path B: The Surgeon (Lance)
```
Heat rises → find vent → open it → messy release → scar
```
**Payoff**: Immediate fix; structural damage.

### Path C: The Body-Worker (Diagnose)
```
Heat rises → "what is burning?" → trace to core → treat root
```
**Payoff**: Resolution; difficult, painful work.

### Path D: The Vessel (Weep)
```
Heat rises → let it flow → sweat/tears/shake → homeostasis
```
**Payoff**: Balance; requires vulnerability.
