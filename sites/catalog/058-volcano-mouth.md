# The Volcano's Mouth

**Practice**: Engineering

---

## State Space

You are at **the crust/mantle interface** — where earth's interior becomes exterior.

| Dimension | Value | Constraint |
|-----------|-------|------------|
| Temperature | 1200°C+ | Instantly lethal |
| Scale | Planetary | Mantle exposed |
| Time | Geological | Deep time visible |

**Tension**: Extreme (physical danger + sublime experience).

---

## Action Set

In **Engineering** practice, your moves are limited by extreme conditions:

| Move | Verb | Effect | Risk |
|------|------|--------|------|
| **Witness** | *suspend* | Stand before the molten | Proximity to death |
| **Abstract** | *widen* | All volcanism, all tectonics | Goes planetary |
| **Retreat** | *branch* | Move to safety | Leaves the site |
| **Study** | *prototype* | Geological investigation | Scientific distance |

**Blocked moves**:
- *Engage* — too vast, too dangerous
- *Prototype* — can't work with 1200°C rock

## Strategy Space

### Path A: Sublime witness
```
Crater's edge → suspend → feel planetary interior → overwhelmed by scale
```
**Payoff**: Direct experience of earth-as-process.

### Path B: Scientific distance
```
Crater's edge → study → volcanism as system → knowledge over experience
```
**Payoff**: Understanding rather than immersion.

### Path C: Retreat
```
Crater's edge → retreat → safety → experience ends
```
**Payoff**: Survival; experience preserved as memory.

### Path D: Cosmic abstraction
```
Crater's edge → widen → all volcanic worlds → Earth as instance
```
**Payoff**: Generalize to planetary process.
