# Chapter 5: Sites — Positions in Possibility

> **Prerequisites**: [Chapter 4: Domains](./04_DOMAINS.md)
> 
> **Key Concepts**: Site, Dimensions, Existence Properties, Derivation
>
> **Learning Objectives**: By the end, you will understand sites as structured positions with embedded dynamics, and know the dimensional space in which sites exist.

---

## What a Site Is

A site is a **structured position in possibility space with embedded dynamics**.

It's not just an idea or a concept. It's a position you can occupy, with:
- A location in dimensional space
- Available movements (gestures)
- Relations to other sites

When you're at a site, you can feel what movements are possible from there.

---

## Examples

Consider these sites (all from the domain of writing × fiction):

- **"The pause in speech"** — a moment of suspension where what comes next is held open
- **"The unreliable narrator"** — a perspectival uncertainty about what's true
- **"The unlived life"** — an absence that haunts by what didn't happen
- **"The threshold"** — a boundary position between inside and outside

These aren't abstract concepts. They're positions. You can go to them. And when you're there, you feel what movements are available.

---

## Site Dimensions

Every site exists somewhere in a multi-dimensional space:

### Ontological Dimension

What kind of thing is this site about?

| Value | Description |
|-------|-------------|
| Substance | A thing that exists |
| Relation | A connection between things |
| Absence | Something not there |
| Process | Something happening |
| Limit | A boundary or edge |
| Tension | A pull between opposites |
| Interference | Patterns from multiple sources |
| Virtuality | Something potential but not actual |

### Scale Dimension

How big or long is this site?

| Value | Description |
|-------|-------------|
| Sub-momentary | Smaller than a moment |
| Momentary | A single moment |
| Extended | Spanning time but less than a lifetime |
| Lifetime | A human lifespan |
| Trans-lifetime | Spanning generations |
| Cosmic | Beyond human scale |

### Temporal Dimension

What's this site's relationship to time?

| Value | Description |
|-------|-------------|
| Instant | A point in time |
| Transition | Movement from one state to another |
| Oscillation | Back and forth |
| Accumulation | Building up over time |
| Memory | Looking back |
| Anticipation | Looking forward |

### Perceptual Dimension

How is this site accessed?

| Value | Description |
|-------|-------------|
| Direct | Immediately perceived |
| Peripheral | Seen from corner of eye |
| Retrospective | Only seen looking back |
| Failure-mediated | Visible through breakdown |
| Other-mediated | Visible through another's experience |
| Somatic | Felt in the body |

### Relational Dimension

Who is involved?

| Value | Description |
|-------|-------------|
| Solitary | One person |
| Dyadic | Two people |
| Small-group | A few people |
| Collective | Many people |
| Non-human | Not people |
| Hybrid | Mix of human and non-human |

### Structural Dimension

What's the site's internal structure?

| Value | Description |
|-------|-------------|
| Simple | Unitary |
| Composite | Made of parts |
| Recursive | Contains itself |
| Paradoxical | Self-contradicting |
| Incomplete | Missing something essential |
| Boundary-only | Just the edge, no inside |

## Dimensional Examples

**"The pause in speech"**
- Ontological: Process (something happening — the not-speaking)
- Scale: Sub-momentary to momentary
- Temporal: Transition (between utterances)
- Perceptual: Direct
- Relational: Dyadic (speaker-listener)
- Structural: Boundary-only (the pause is all edge)

**"The unlived life"**
- Ontological: Absence
- Scale: Lifetime
- Temporal: Memory
- Perceptual: Retrospective
- Relational: Solitary
- Structural: Incomplete (what didn't happen)

---

## Existence Properties

How does this site exist?

| Property | Description |
|----------|-------------|
| Engagement-dependent | Only exists while attended to |
| Persistent | Continues whether attended or not |
| Periodic | Comes and goes |
| Conditional | Exists only under certain conditions |

**"The pause in speech"** is engagement-dependent — it's only a site while someone's attending to it as such.

**"The summit of the mountain"** is persistent — it's there whether anyone's thinking about it.

**"The commute"** is periodic — it comes and goes with the rhythm of workdays.

---

## Derivation

Sites don't exist in isolation. They're connected through derivation:

### Parent Sites

The site this one came from. "The unreliable narrator" might be derived from "the narrator" by adding the property of unreliability.

### Child Sites

Sites derived from this one. "The unreliable narrator" might parent "the self-deceived narrator" and "the lying narrator."

### Sibling Sites

Sites sharing the same parent. "The omniscient narrator" and "the limited narrator" are siblings.

### Derivation Chains

You can trace how you arrived at a site:

```
"Speech" 
  → "Pause in speech" (by NARROW: focus on gaps)
    → "The pregnant pause" (by NARROW: add significance)
      → "The pause before confession" (by NARROW: add context)
```

---

## Site Fertility

Some sites are more generative than others:

**High fertility**: Many gestures available, many derivations possible. "The threshold" has high fertility — you can go many places from there.

**Low fertility**: Few gestures available, feels like an endpoint. "The corpse" has lower fertility — certain movements are blocked.

Fertility isn't good or bad. Endpoint sites (low fertility) are where things resolve. Generative sites (high fertility) are where things branch.

---

## Finding and Moving to Sites

You don't discover sites randomly. You:

1. **Enter a domain** (practice engages field)
2. **Inherit known sites** from domain's accumulation
3. **Generate new sites** by following gestures from current position
4. **Derive sites** by applying operations to existing sites
5. **Emerge sites** from flux (if your practice permits)

Movement through site-space is the core creative activity. 

---

## Summary

- **Sites** are structured positions with embedded dynamics
- Sites exist in **dimensional space** (ontological, scale, temporal, perceptual, relational, structural)
- Sites have **existence properties** (engagement-dependent, persistent, periodic, conditional)
- Sites connect through **derivation** (parent, child, sibling chains)
- Sites vary in **fertility** (how many movements are possible from here)
- You find sites by entering domains, inheriting, generating, deriving, or emerging

## Exercises

### Warm-up

**5.1 The Pre-Phone Check**

**Position**: You are at the site "The moment before you check your phone."

| Dimension | Value | Notes |
|-----------|-------|-------|
| **Ontological** | Virtuality + Tension | The phone *contains* a potential world; you feel the pull |
| **Temporal** | Anticipation | Craving the hit |
| **Structural** | Boundary-only | You are on the edge of the digital |

**Question**: What is the *exact* structure of this site? What gesture is about to fire? (Hint: COMMIT).

**5.2 The Avoided Conversation**

**Position**: You are at the site "The conversation you've been avoiding."

| Existence Type | Test |
|----------------|------|
| **Engagement-dependent** | Exists only when you think about it |
| **Persistent** | Exists even when you're not thinking about it (shapes behavior) |

**Question**: Is this site Persistent? (Hint: Yes. It's a "gravity well" invisible to the eye but visible to the trajectory—you avoid certain rooms, topics, people.)

---

### Standard

**5.3 Deriving "The Apology"**

**Position**: "The Apology" is a site. Derive three child sites:

| Derivation Method | Child Site |
|-------------------|------------|
| **Add Property** | "The Preemptive Apology" (apologizing before doing the bad thing) |
| **Add Context** | "The Public Apology" (performance vs. contrition) |
| **Add Failure** | "The Apology That Demands Forgiveness" (transaction, not gift) |

**Question**: Which derivation produces the most *fertile* child?

**5.4 Fertility Comparison**

**Position**: Compare two sites:

| Site | Fertility | Available Gestures |
|------|-----------|-------------------|
| **The Doorway** | High | Go through, stand in, block, look through |
| **The Locked Door** | Low (locally) | Knock, break, turn away |

**However**: The Locked Door has high *narrative* fertility (Why? Who has the key?) but low *spatial* fertility.

**Question**: What determines fertility? (Hint: number of available moves × their variance.)

**5.5 Temporal Dimensions (Morning Routine)**

**Position**: Generate a site at each temporal dimension:

| Temporal Dimension | Site |
|--------------------|------|
| **Instant** | "The Alarm" (the shock of return) |
| **Transition** | "The Shower" (liquid state between sleep and costume) |
| **Accumulation** | "The Coffee Stain" (evidence of the routine's repetition) |

**Question**: How do they relate? (Hint: Instant triggers Transition; Accumulation is the fossil record.)

---

### Challenge

**5.6 Recursive + Boundary-Only**

**Position**: Design a site that is both recursive (contains itself) and boundary-only (just the edge, no inside).

| Example | Why It Works |
|---------|--------------|
| **The Klein Bottle** | One continuous surface (boundary) that folds into itself (recursive) |
| **Bureaucracy** | All interface (forms, rules) with no center; rules about rules |

**Question**: Can such a site exist? (Yes. It produces "Absurdity.")

**5.7 Failure-Mediated Sites**

**Position**: Some sites only appear through breakdown.

| Domain | Failure-Mediated Site | Breakdown Trigger |
|--------|----------------------|-------------------|
| **Health** | "The breath" | Asthma, running |
| **Infrastructure** | "The electricity" | Blackout |
| **Trust** | "The truth" | Being lied to |

**Question**: What would it take to perceive them *before* failure? (Hint: "Voluntary Failure"—fasting, camping, skepticism.)
